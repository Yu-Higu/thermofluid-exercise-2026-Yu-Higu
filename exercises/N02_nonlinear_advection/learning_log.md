## 予想と式・コード

- N01の一定速度移流との違い，左側の広がりと右側の急峻化の予想：
  N01では移流速度が一定だが，N02のBurgers方程式では局所速度がuとなる．初期値は左側の段差でuが1から2へ増加し，u=2の部分がより速く移流するため，左側は広がると予想した．右側の段差ではuが2から1へ減少するため，波形が急峻になると予想した．
- 保存形の流束差分と非保存形の差，式・配列・添字の対応：
  保存形は `∂u/∂t + ∂f(u)/∂x = 0`，`f(u)=u²/2` であり，滑らかな解では非保存形 `∂u/∂t + u∂u/∂x = 0` と等価である．実装は旧配列から `u_new[i] = u_old[i] - (dt/dx) * (f(u_old[i]) - f(u_old[i-1]))` と計算する．周期境界では `i=1` の左隣を `n` とする．不連続を含む数値計算では，流束差を用いる保存形として更新する．
- 固定／周期の格子，周期添字，境界，バッファ交換の説明：
  計算領域は長さ2で，固定境界はnx=81，周期境界はnx=80とし，どちらもdx=0.025とした．固定境界では1ステップ後に左端を1，右端を直前の格子点の値にする．周期境界では端点を固定せず，先頭の左隣を配列末尾として扱う．各ステップでは独立した旧・新配列を使い，境界を適用した後に `u_old, u_new = u_new, u_old` と参照を交換する．
