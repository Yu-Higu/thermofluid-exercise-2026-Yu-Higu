## 実行前予想

- 四公式の成分証明で，積の微分や混合偏微分の交換をどこで使うと予想したか：
  - 理論を整理すると，curl grad = 0，div curl = 0，curl curl では混合偏微分の交換が必要であり，積の発散では積の微分だけが必要となると予想した．
- 前進・後退・中心差分の誤差は刻み幅を半分にするとどう変わると予想したか：
  - Taylor 展開から，前進・後退差分の誤差は半分，中心差分の誤差は約1/4になると予想した．
- ベクトル解析四公式の残差は格子を細かくするとどう変わると予想したか：
  - 中心差分を使うため，格子幅を半分にすると残差は概ね4分の1になると予想した．

## 証明：curl grad = 0

- 使用した定義：
  - grad φ = (∂xφ, ∂yφ, ∂zφ)，curl B = (∂yBz - ∂zBy, ∂zBx - ∂xBz, ∂xBy - ∂yBx)．
- 成分展開：
  - curl(grad φ) = (∂y∂zφ - ∂z∂yφ, ∂z∂xφ - ∂x∂zφ, ∂x∂yφ - ∂y∂xφ)．
- 混合偏微分を交換した箇所：
  - 各成分で偏微分の順序を交換する．二階偏導関数が連続（φ ∈ C²）なら混合偏微分が等しい．
- 結論：
  - すべての成分が0なので curl grad φ = 0 が導き出された．

## 証明：div curl = 0

- 使用した定義：
  - div B = ∂xBx + ∂yBy + ∂zBz と curl A の定義．
- 成分展開：
  - div(curl A) = ∂x(∂yAz - ∂zAy) + ∂y(∂zAx - ∂xAz) + ∂z(∂xAy - ∂yAx)．
  - 展開すると ∂x∂yAz - ∂x∂zAy + ∂y∂zAx - ∂y∂xAz + ∂z∂xAy - ∂z∂yAx．
- 混合偏微分を交換した箇所：
  - Az，Ay，Ax に関する各混合偏微分をそれぞれ交換すると項が相殺する．十分条件は A が C²に属すること．
- 結論：
  - div(curl A) = 0．

## 証明：積の発散

- 使用した定義：
  - div(φA) = Σᵢ ∂ᵢ(φAᵢ)，grad φ = (∂xφ, ∂yφ, ∂zφ)．
- 積の微分による成分展開：
  - div(φA) = ∂x(φAx) + ∂y(φAy) + ∂z(φAz)
    = (∂xφ)Ax + (∂yφ)Ay + (∂zφ)Az + φ(∂xAx + ∂yAy + ∂zAz)
    = A・grad φ + φ div A．
- 必要な滑らかさと，混合偏微分の交換を使わない理由：
  - φ と A の各成分が一階偏微分可能であればよい．計算には同じ座標方向の一階微分と積の微分しか現れず，混合偏微分は使う必要がない．
- 結論：
  - div(φA) = A・grad φ + φ div A．

## 証明：curl curl

- ベクトルLaplacianの定義：
  - ∇²A = (∇²Ax, ∇²Ay, ∇²Az)，各成分について ∇² = ∂x² + ∂y² + ∂z²．
- 三成分の展開：
  - curl(curl A)x = ∂x∂yAy + ∂x∂zAz - ∂y²Ax - ∂z²Ax．
  - curl(curl A)y = ∂y∂xAx + ∂y∂zAz - ∂x²Ay - ∂z²Ay．
  - curl(curl A)z = ∂z∂xAx + ∂z∂yAy - ∂x²Az - ∂y²Az．
  - grad(div A) - ∇²A の各成分を展開すると，対応する上記成分と一致する．
- 混合偏微分を交換した箇所と条件：
  - curl(curl A) の展開にある ∂y∂xAx，∂z∂xAx，∂z∂yAy 等を grad(div A) の対応する順序に合わせる．十分条件は A が C²に属していること．
- 結論：
  - curl(curl A) = grad(div A) - ∇²A．

## 前進・後退・中心差分

- 3つの差分式：
  - 前進差分：(f(x+h) - f(x))/h
  - 後退差分：(f(x) - f(x-h))/h
  - 中心差分：(f(x+h) - f(x-h))/(2h)
- 参照する近傍点の違い：
  - 前進差分は x と x+h，後退差分は x-h と x，中心差分は x-h と x+h を使うという違いがある．
- Taylor 展開から予想する収束次数：
  - 前進・後退差分は一次であり，誤差 O(h)となると予想される．中心差分は二次であり，誤差 はO(h²)となると考えられる．

## 発展：積の回転と移流項の変形

### 積の回転と圧力勾配加速度

- 積の回転公式：
  - curl(φA) = φ curl(A) + grad(φ) × A．例えば x 成分は ∂y(φAz) - ∂z(φAy) を積の微分で展開すると，φ(∂yAz - ∂zAy) + (∂yφ)Az - (∂zφ)Ay となり，右辺の x 成分に一致する．他の成分も同様である．
  ―これは，密度の等高線と圧力の等高線が斜めに交差する領域では，トルクが発生して新たな渦度が生み出されることを示している．
- 圧力勾配加速度の回転：
  - φ = 1/ρ，A = grad(p) とおく．curl(grad(p)) = 0 と grad(1/ρ) = -(1/ρ²)grad(ρ) より，curl((1/ρ)grad(p)) = -(1/ρ²)grad(ρ) × grad(p)．ここでは ρ ≠ 0 かつ各場が必要なだけ滑らかとする．
- 渦度方程式への影響と密度一定仮定：
  - 密度一定なら grad(ρ) = 0 なので圧力由来の渦度生成項は消える．密度勾配と圧力勾配が平行でない場合はこの項が一般に残り，渦度を生成する．一定密度の仮定はこの効果を除き，流れの運動や粘性拡散に注目しやすくする．

### 移流項の変形

- 恒等式：
  - (u・grad)u = 1/2 grad(|u|²) - u × (curl(u))．x 成分では，右辺の 1/2 grad(|u|²) のuᵧ∂ₓuᵧ，u_z∂ₓu_z が外積項の対応する負の項と相殺し，左辺の uₓ∂ₓuₓ + uᵧ∂ᵧuₓ + u_z∂_zuₓ が得られる．他の成分も同様である．この恒等式に非圧縮条件は不要であり，u が C¹ 級なら成り立つ．
- 無次元 Navier–Stokes 方程式：
  - 恒等式を代入して勾配項をまとめると，∂ₜu - u × ω = -grad(p + |u|²/2) + (1/Re)∇²u，ただし ω = curl(u) となる．速度の大きさに由来する勾配を圧力勾配とまとめ，残る移流の寄与を速度と渦度の外積で表せる．
- 渦なし領域：
  - ω = 0 なら外積項は消え，移流項は 1/2 grad(|u|²) のみとなる．定常流かつ非粘性の場合，方程式はベルヌーイの式に変形される．
