# N04 学習ログ

## モデルの選択と予想

- SELECTED_MODEL：`:nonlinear`．速度場自身が移流速度となるBurgers型を選んだ．
- 無次元の保存形方程式は `u_t + (u^2/2)_x = D u_xx`．流束は `F(u)=u^2/2`，`u`は速度，`D`は拡散係数，周期積分は速度の積分であり熱量ではない．移流のみでは段差が移流し，拡散のみでは段差が平滑化し，両方ではその両方が現れると予想した．
- 全計算を領域 `[0,2)` の周期格子で実施．解析モードの平均速度は1で，矩形初期値の解析解としては使わない．

## 式・実装・テストの対応

- 非線形選択流束 `u^2/2`（負の `u` は検証で拒否），線形を指定した場合の `speed*u` を実装した．更新では `i=1` の左隣を末尾，末尾の右隣を先頭として，保存形の流束差と中心拡散差分を同じ旧配列から計算する．
- 合成安定条件は `C+2Fo = (a/dx + 2D/dx^2)dt <= 1`．したがって上限は `safety/(a/dx + 2D/dx^2)`．移流と拡散の個別上限のminでは和の条件を保証できない．`a=2, dx=0.5, D=0.1, safety=0.8` では `dt=1/6`．
- 必須4群：非対称4点の1ステップ期待値で周期端・移流拡散の符号と旧配列不変を確認．定数場と積分で不変量を確認．移流なし・拡散なしの極限で各項を分離して確認．標準計算で最終時刻一致，`C+2Fo<=0.8`，有限性と初期範囲を確認する．
- 自作1（周期積分保存）：非対称な5点 `[0.8,1.1,1.7,1.3,0.9]` を `dx=0.4, dt=0.004, D=0.05` で25ステップ計算．独立に `dx*sum(u0)=2.32` と求め，積分差の許容誤差を `1e-12` とした．これは約125回の浮動小数演算で蓄積する丸め誤差より余裕を持たせた値．保存則違反を検出できるが，局所の値誤りが積分で相殺する可能性はある．
- 自作2（格子収束）：解析モードを同じ `t=1` まで `nx=40,80,160`，標準の合成安定刻みで計算し，最大絶対誤差を解析解と比較．誤差は `[0.0235385, 0.0133952, 0.00722680]`，観測次数は `[0.8133, 0.8903]` で，各格子間で誤差が減少し一次精度に期待する `0.8〜1.2` の範囲に入った．滑らかな1モードの全体誤差を見る検査であり，矩形初期値や全ての局所誤りを検査するものではない．
- 実行：`julia --startup-file=no --project=. -e 'include("exercises/N04_advection_diffusion/tests.jl")'` — 必須11件，自作4件が通過．
- 回帰：`julia --startup-file=no --project=. -e 'using Pkg; Pkg.test()'` — コマンド終了コード0，N04は15/15通過．
## 結果と考察

- 選択モデルの結果：[比較図](results/nonlinear/comparison.png)，[積分保存図](results/nonlinear/conservation.png)，[収束図](results/nonlinear/convergence.png)，[数値サマリー](results/nonlinear/summary.toml)．
- 標準条件は `nx=80, dx=0.025, dt=0.002, steps=500, t_final=1`．移流のみは `max CFL=0.16, Fo=0`，拡散のみは `max CFL=0, Fo=0.32`，合成は `max CFL=0.16, Fo=0.32, max(C+2Fo)=0.8`．
- 初期離散積分 `2.5250000000000004`．合成計算の最終積分 `2.5249999999999995`，符号付き変化 `-8.88e-16`．全時刻の最小・最大は `1.0, 2.0`．移流のみ・拡散のみも積分差は丸め誤差程度．
- 拡散項は指定した物理拡散を表す一方，一次精度の風上流束にも数値拡散がある．図の移流のみの平滑化を物理拡散だけと解釈できない．拡散のみとの比較と合成条件で両者を区別した．
- 予測した周期積分保存と有限範囲は標準計算で確認できた．格子収束次数は時間一次・空間一次の移流離散と整合する．
