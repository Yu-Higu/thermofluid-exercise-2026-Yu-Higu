## 予想と式・コード

- 無次元の温度・時刻・熱拡散率と物理量の対応：
  - ここでは温度 u は無次元化したスカラー，時間 t は無次元時刻，拡散率 D は 0.1 であり，支配方程式は ∂u/∂t = D ∂²u/∂x² である．
  - 空間域は [0, 2] の無次元長さで，格子間隔 dx = 2/(nx-1) で定義される．
- 内部点差分と旧配列・新配列，バッファ交換の対応：
  - 内部点は u_new[i] = u_old[i] + r (u_old[i-1] - 2u_old[i] + u_old[i+1]) で更新する．ここで r = D dt / dx² で，旧配列のみを使って新しい配列を作る．
  - 最後に apply_boundary! で境界を付け直し，u_old と u_new を交換して次時刻へ進む．これにより，1ステップ計算中に旧配列が壊れないことを保証する．
- 固定温度と断熱で熱量の変化が異なる理由：
  - 固定温度境界では端が 0 に固定されるので，熱が外部に逃げて熱量が減少する．
  - 断熱境界では熱流束が 0 であり，境界を通じて出入りしないため，理想的には熱量が保存される．実際には数値誤差でほぼ 0 に近い変化のみが残る．
- 断熱端の係数2，端点半セルと台形則の重み：
  - 断熱境界では境界点のゴースト点を鏡像近似し，u_ghost = u_1 + 2r(u_1 - u_0) などの更新式を用いる．係数 2 は半セル分の影響を表している．
  - 熱量 H は端点に 1/2 の重みを持つ台形則で H = dx (0.5u_1 + Σ_{i=2}^{N-1} u_i + 0.5u_N) と定義される．

## 必須4群と自作2つのテスト

- 配布済み必須4群の入力・期待値・判定の意味：
  - 小配列1ステップと旧配列不変: 断熱境界での 1 ステップ更新が期待どおりで，u_old が変化しないことを確認する．
  - 定数場と固定端: 定数場では変化しないこと，固定端では端点が 0 になることを確認する．
  - 台形則の熱量: H = dx(0.5u_1 + ... + 0.5u_N) により，離散熱量が正しく計算されるか確認する．
  - 標準計算の安定性: 固定端・断熱端の両方で 0 < fo <= 0.5，全時刻で有限値，極値が [0, 1] 内に収まることを確認する．
- 自作1（断熱熱量保存）：非対称非定数配列，ステップ数，独立に求めた初期熱量，許容誤差と根拠：
  - 配列 [0.2, 0.9, 1.5, 0.8, 0.6, 1.1, 0.4] を 20 ステップ更新し，初期熱量 H0 を独立に計算した．断熱境界では理論上 H は保存されるので，許容誤差 atol = 1e-12 を採用した．
  - これは数値誤差の桁数が 1e-12 程度であることを想定したもので，実際には 1e-16 オーダーの差に収まっている．
- 自作1で検出できる誤り／できない誤り：
  - 端点更新式に 1 ではなく 2 を誤って入れた場合や，総和の重みを誤る場合に検出できる．
  - 逆に，内部点の更新式が一部だけ間違っていても，保存が偶然保たれる場合は検出に漏れる可能性がある．
- 自作2（正弦解析解と格子収束）：格子・時刻・fo，誤差指標，許容範囲と根拠：
  - 41, 81, 161 点で固定端の解析解と数値解を比較し，最大絶対誤差を評価した．r = 0.4 で同時刻 t = 1.0 を比較し，誤差が 1.39e-4 -> 3.47e-5 -> 8.67e-6 と減少した．
  - 収束次数 order = log2(E_N / E_2N) は約 2.00 で，空間2次のスキームとして妥当である．
- 自作2で検出できる誤り／できない誤り：
  - 空間差分の係数を誤る，境界条件の取り扱いが不正，時間刻みの取り違えなどは検出しやすい．
  - 低い格子数では誤差の減少が見えないため，収束性の測定に用いる点数や時刻を十分に取らないと見逃す場合がある．
